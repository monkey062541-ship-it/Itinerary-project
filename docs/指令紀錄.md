### 6～8. Render 建置失敗排查

> （截圖）Exited with status 1 while building your code.
> error: failed to solve: failed to read dockerfile: open Dockerfile: no such file or directory

**處理**：分三次排查。

| commit | 改動 | 結果 |
|---|---|---|
| `81ea56b` | 固定 Python 3.12.8、移除 `uvicorn[standard]` | 未解決，屬推測 |
| — | 本機以 Python 3.12 模擬解相依，34 個套件全有預編譯檔、無衝突 | 排除相依性問題 |
| `92bf05c` | 新增 `Dockerfile` 與 `.dockerignore` | 對症：服務的 Language 被設為 Docker |

**真正原因**：Render 服務建立時 Language 選成 Docker，建置時找不到 `Dockerfile`，
在安裝套件前就中止。Docker 模式下 dashboard 的 Build／Start Command 會被忽略，
一切以 Dockerfile 的 `CMD` 為準。

### 9. 機器人無法加入群組

> 我現在邀請我的機器人進去群組都不加怎麼辦

**處理**：非程式問題。LINE 官方帳號預設拒絕被邀請加入群組，需至
[LINE Official Account Manager](https://manager.line.biz) → 設定 → 帳號設定 →
「允許被加入群組、多人聊天室」改為**接受**。此設定在 LINE Developers Console
只能檢視、不能修改。

**待處理**：進入群組後，目前程式會回應群組內的每一則訊息，需要收斂為
只回應關鍵字、認不出來時保持安靜。
